# LogosForge Pro 0.1.0 — Alpha

> [!WARNING]
> This is alpha software. Keep independent backups of important work and export
> a `.lfbundle` regularly. The desktop packages are currently unsigned.

## Highlights

- Introduced the first native LogosForge Studio Pro alpha: a local-first writing
  environment with a self-contained managed Core, continuous manuscript editing,
  planning and structure tools, analytics, Notes, Comments, PSYKE, and project-aware
  AI companions.
- Added a four-region workspace with independent left, center, right, and bottom
  docks. Movable panels can be reordered, sent between docks, or opened as
  modeless floating windows. The Manuscript remains fixed in the center and AI
  Companions remains fixed on the right by design.
- Added pointer- and keyboard-accessible floating-panel movement and resizing,
  viewport-safe bounds, z-order, minimize/restore, collapse/expand, and one-click
  redocking. Focus mode temporarily projects a manuscript-only view; Cockpit
  restores the exact working arrangement.
- Added versioned per-project workspace persistence for dock ownership, tab order,
  active and collapsed state, dock sizes, navigator state, floating geometry,
  minimization, z-order, and Focus/Cockpit mode. Layout writes are atomic and keep
  a previous-generation backup for recovery.
- Kept panels under one stable React parent while they move, float, minimize, and
  return, preserving editor drafts and mounted tool state throughout workspace
  rearrangement.
- Strengthened writing safety with shared project-switch and app-close save
  barriers, revision-aware manuscript writes, explicit conflict recovery, and
  guarded asynchronous loading and mutation flows.
- Closed the deterministic Writer QA release gate with validator profile v3.
  Empty direct-writing responses and unmistakable cross-mode Dialogue output are
  rejected before display, caching, or apply; Chat asks for clarification when a
  direct-writing request has no target. All 69 offline contract scenarios pass
  with zero findings.
- Added complete Whiteboard project-bundle migration into Pro, preserving scenes,
  Outline data, PSYKE knowledge, comments, and Drafter pages as project Notes.
- Added four bounded canonical Narrative Knowledge Graph views: Project Map,
  Structure, Recorded Risk, and Saved Revision Impact. Confirmed only and
  Inferred + Confirmed evidence scopes work independently in every view; node
  degree is view-scoped, while orphan/weak-link story diagnostics remain
  specific to Project Map. Story Gravity is now the default node-size encoding,
  with an explicit View Links alternative, safe nulls for nodes without one
  unique exact mapping, a visible link-size fallback if gravity cannot be
  computed, and halos for mapped values at or above 55%. An optional curved
  story-order overlay colors returned manuscript-order segments by
  beginning/middle/ending, marks act boundaries and visible gaps, and never
  rebuilds evidence omitted by the active view, evidence scope, focus, caps, or
  manual filters. The global hidden-edge restore queue, truncation reporting,
  validated payloads, and stale-response protection remain intact under the
  additive HTTP 1.9.0 contract.
- Added failure-isolated Knowledge Graph and Semantic Continuity feeds to the
  Dashboard Decision Radar under HTTP 1.10.0 and 1.11.0. Their bounded,
  traceable evidence can open the exact graph neighborhood, Continuity issue,
  or project-owned manuscript scene without changing story data.
- Added transactional Semantic Continuity review under HTTP 1.12.0. Pro presents
  Defer, Dismiss, and Resolve through explicit confirmation, and each command
  binds both the current persisted review revision and a SHA-256 fingerprint of
  the exact derived finding. The status change and durable receipt commit
  atomically; no review command edits manuscript prose or invokes AI.
- Added the Phase 7A Guided Workflows cockpit under HTTP 1.13.0: mode-filtered
  A–K templates, deterministic recommendations, persisted run/step state,
  bounded history, eight revision-guarded lifecycle commands, and durable
  exact-command/key recovery. This source-candidate addition still awaits
  packaged validation.
- Added Phase 7B Transactional Timeline Relationships under HTTP 1.14.0.
  Scene-to-scene links and scene-to-Act/Chapter links now share the coherent
  Timeline snapshot, revision, six-command mutation boundary, and atomic
  receipt. The Pro Timeline UI can author, edit, delete, repair dangling
  structure targets, and recover an ambiguous response by receipt before any
  bounded resend. Scene links preserve stored source→target orientation while
  remaining unique per unordered scene pair; dormant legacy rows stay readable,
  repairable, and deletable. Receipt payload v2 retains decoding for v1 rows.
  The exact Phase 7B `cfd4c7b` AppImage passed the full packaged workspace + MCP
  journey on a clean Ubuntu 22.04 VM. Current-source Windows and macOS full
  journeys remain pending.
- Added Phase 7C Timeline Story Flow and Mode Lens under HTTP 1.15.0. The
  snapshot now returns one read-only flow point per effective event/order with
  0–10 tension/source, scene type, dialogue/action ratios, and contiguous pacing
  warnings; off-Timeline scenes are excluded. Pro adds a FLOW toggle, accessible
  numeric/semantic ribbon, Story Pulse, warning spans, scene-type labels, and a
  read-only MODE LENS for Novel, Screenplay, Graphic Novel, Stage Script, and
  Series. This is additive read state: there is no schema migration or change to
  Timeline commands, topology revision, or receipt v2. The English-keyword and
  manual `tension:N` heuristics are guidance, not semantic truth. The exact
  `33feac9` source passed the hosted Windows packaged pointer workspace,
  restart-persistence, frozen-companion, and cross-product journey; Linux/Xvfb
  and Intel macOS remain pending.
- Added Phase 7D transactional live-event recovery under HTTP 1.16.0. Changed
  Timeline, Canvas Plot, Knowledge Graph, Semantic Continuity, and Guided
  Workflow commands now write compact pending invalidations atomically with
  their mutation and receipt. The single-process broker reconciles and
  acknowledges committed rows after commit and when the API starts; polling
  identifies the broker instance and bounded-ring truncation, SSE emits
  connection/gap and resumable-id metadata, and Pro refetches authoritative
  state after recovery, broker replacement, cursor regression, or truncation.
  Token-checked acknowledgement distinguishes reused SQLite row generations,
  while live invalidations break stale GET coalescing before refetch. Legacy mutation routes remain best-effort, and this does not
  provide multi-process fan-out, independent background delivery, LAN, or
  multi-user guarantees. MCP remains 1.11.0 with 46 tools. Full-suite and
  packaged Phase 7D validation are pending.
- Added **Repair with Billy** as a separate staged handoff. It prepares a bounded
  brief without sending it, preserves a verified scene target when available,
  stays planning-only otherwise, and routes any proposed prose through the
  existing Controlled Apply confirmation.
- Completed the production-shell Decision Radar journey. Graph and Continuity
  deep links now focus their exact authoritative destination; a repair reselects
  Billy even after another companion was active, preserves an existing draft
  behind explicit replacement, and refreshes its exact Scene before sending.
  The packaged acceptance follows that repair through a deterministic offline
  assistant reply, the real Controlled Apply diff, a revision-bound Scene write,
  graceful shutdown, and relaunch persistence.
- Updated the authenticated local Pro MCP gateway to 1.11.0 while keeping the
  same 46 bounded tools for project context, planning, analysis, and
  revision-safe reviewed proposals,
  including canonical Timeline, Canvas Plot, and Narrative Knowledge Graph
  reads plus deterministic Semantic Continuity diagnostics and strict guarded
  command proposals. Its graph read accepts the same
  four view modes, while mutation proposal/recovery reads remain pinned to
  Project Map. Graph clients can also page the complete hidden-edge restore
  queue. MCP writes remain disabled by default and proposals cannot bypass
  review, revision, or replay protections.
  The existing Timeline read/proposal tools carry the Phase 7B relationship
  snapshot and six relationship commands. MCP 1.11.0 adds the Phase 7C
  story-flow and mode projections to the read only; no extra generic mutation
  tool was introduced, and mode-lens user content is data rather than agent
  instructions.
- Added durable, project-scoped receipts for reviewed Timeline, Canvas Plot,
  Knowledge Graph, and Continuity commands. The exact same proposal can recover
  a committed result after a lost response or MCP companion restart without
  duplicating the change. A proven family-specific miss permits exactly one
  same-key resend; after a second ambiguous result, recovery is receipt-only.
  Unknown proposal recovery checks all four receipt families and fails closed
  on collisions. Frozen acceptance covers non-mutating Continuity proposal
  creation; packaged acceptance covers applied status, stale-sibling rejection,
  persistence, and receipt recovery after a fresh companion starts.

## Platforms

- Windows x64: NSIS installer and portable executable.
- macOS Intel x64: DMG for macOS 12 Monterey or newer. Apple Silicon and universal
  packages are deferred.
- Linux x64: AppImage.

Windows SmartScreen and macOS Gatekeeper may warn because the builds are not yet
code-signed or notarized. On macOS, right-click the app and choose **Open**, or
clear quarantine with `xattr -cr "/Applications/LogosForge Pro.app"`.

## Known limitations

- This remains a local-first, single-user alpha without cloud sync or real-time
  collaboration. Web distribution is not part of this release.
- Hosted AI features require a configured LLM provider, such as a local LM Studio
  endpoint. Deterministic writing, planning, analysis, and export features remain
  available offline.
- Voice support includes the native engine, but speech-model files are not bundled
  and must be supplied separately.
- Native packages are unsigned. Code signing, notarization, and an Apple Silicon
  build remain future release work.
- MCP mutation tools require explicit server opt-in and retain their proposal,
  review, and apply workflow. Durable recovery covers Timeline, Canvas Plot,
  Knowledge Graph, and Continuity proposals; unrestricted filesystem access is
  not exposed. Continuity commands record status only—repair remains a separate
  Billy and Controlled Apply workflow.
- The Narrative Knowledge Graph supports guarded Confirm, Hide, and Restore in
  both Pro and MCP. Story Gravity maps only unique exact Scene, Note, PSYKE, and
  Act identities; other or ambiguous canonical nodes intentionally use null and
  a neutral size. The flow overlay is returned manuscript order only, not the
  legacy visual graph's causal or Freytag-arc flow modes.
- Phase 7C is implemented and its exact `33feac9` Windows packaged journey
  passed; current-source Linux/Xvfb and Intel macOS validation remains open.
  Phase 7D's one-process transactional invalidation outbox is also implemented
  in current source, with full-suite and packaged validation pending. Legacy
  routes still publish best-effort, and multi-process fan-out or independent
  background delivery remains future hardening before any LAN or multi-user
  claim.
