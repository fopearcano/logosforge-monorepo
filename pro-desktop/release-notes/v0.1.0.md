# LogosForge Pro 0.1.0 — Alpha

> [!WARNING]
> This is alpha software. Keep independent backups of important work and export
> a `.lfbundle` regularly. The desktop packages are currently unsigned.

## Highlights

- Introduced the first native LogosForge Studio Pro alpha: a local-first writing
  environment with a self-contained managed Core, continuous manuscript editing,
  planning and structure tools, analytics, Notes, Comments, PSYKE, and project-aware
  AI companions.
- Added a four-region workspace with independent left, center, right, and bottom
  docks. Movable panels can be reordered, sent between docks, or opened as
  modeless floating windows. The Manuscript remains fixed in the center and AI
  Companions remains fixed on the right by design.
- Added pointer- and keyboard-accessible floating-panel movement and resizing,
  viewport-safe bounds, z-order, minimize/restore, collapse/expand, and one-click
  redocking. Focus mode temporarily projects a manuscript-only view; Cockpit
  restores the exact working arrangement.
- Added versioned per-project workspace persistence for dock ownership, tab order,
  active and collapsed state, dock sizes, navigator state, floating geometry,
  minimization, z-order, and Focus/Cockpit mode. Layout writes are atomic and keep
  a previous-generation backup for recovery.
- Kept panels under one stable React parent while they move, float, minimize, and
  return, preserving editor drafts and mounted tool state throughout workspace
  rearrangement.
- Strengthened writing safety with shared project-switch and app-close save
  barriers, revision-aware manuscript writes, explicit conflict recovery, and
  guarded asynchronous loading and mutation flows.
- Added complete Whiteboard project-bundle migration into Pro, preserving scenes,
  Outline data, PSYKE knowledge, comments, and Drafter pages as project Notes.
- Added four bounded canonical Narrative Knowledge Graph views: Project Map,
  Structure, Recorded Risk, and Saved Revision Impact. Confirmed only and
  Inferred + Confirmed evidence scopes work independently in every view; node
  degree is view-scoped, while orphan/weak-link story diagnostics remain
  specific to Project Map. Story Gravity is now the default node-size encoding,
  with an explicit View Links alternative, safe nulls for nodes without one
  unique exact mapping, a visible link-size fallback if gravity cannot be
  computed, and halos for mapped values at or above 55%. An optional curved
  story-order overlay colors returned manuscript-order segments by
  beginning/middle/ending, marks act boundaries and visible gaps, and never
  rebuilds evidence omitted by the active view, evidence scope, focus, caps, or
  manual filters. The global hidden-edge restore queue, truncation reporting,
  validated payloads, and stale-response protection remain intact under the
  additive HTTP 1.9.0 contract.
- Added the authenticated local Pro MCP gateway 1.8.0 with 45 bounded tools for
  project context, planning, analysis, and revision-safe reviewed proposals,
  including canonical Timeline, Canvas Plot, and Narrative Knowledge Graph
  reads and strict guarded command proposals. Its graph read accepts the same
  four view modes, while mutation proposal/recovery reads remain pinned to
  Project Map. Graph clients can also page the complete hidden-edge restore
  queue. MCP writes remain disabled by default and proposals cannot bypass
  review, revision, or replay protections.
- Added durable, project-scoped receipts for reviewed Timeline, Canvas Plot,
  and Knowledge Graph commands. The exact same proposal can recover a committed
  result after a lost response or MCP companion restart without duplicating the
  change; other MCP write families remain conservatively non-retryable when
  their outcome is unknown.

## Platforms

- Windows x64: NSIS installer and portable executable.
- macOS Intel x64: DMG for macOS 12 Monterey or newer. Apple Silicon and universal
  packages are deferred.
- Linux x64: AppImage.

Windows SmartScreen and macOS Gatekeeper may warn because the builds are not yet
code-signed or notarized. On macOS, right-click the app and choose **Open**, or
clear quarantine with `xattr -cr "/Applications/LogosForge Pro.app"`.

## Known limitations

- This remains a local-first, single-user alpha without cloud sync or real-time
  collaboration. Web distribution is not part of this release.
- Hosted AI features require a configured LLM provider, such as a local LM Studio
  endpoint. Deterministic writing, planning, analysis, and export features remain
  available offline.
- Voice support includes the native engine, but speech-model files are not bundled
  and must be supplied separately.
- Native packages are unsigned. Code signing, notarization, and an Apple Silicon
  build remain future release work.
- MCP mutation tools require explicit server opt-in and retain their proposal,
  review, and apply workflow. Durable recovery covers Timeline, Canvas Plot,
  and Knowledge Graph proposals; unrestricted filesystem access is not exposed.
- The Narrative Knowledge Graph supports guarded Confirm, Hide, and Restore in
  both Pro and MCP. Story Gravity maps only unique exact Scene, Note, PSYKE, and
  Act identities; other or ambiguous canonical nodes intentionally use null and
  a neutral size. The flow overlay is returned manuscript order only, not the
  legacy visual graph's causal or Freytag-arc flow modes.
