# LogosForge Pro 0.1.2 — Alpha

> [!WARNING]
> This is alpha software. Keep independent backups of important work and export
> a `.lfbundle` regularly. The desktop packages are currently unsigned.

## What this prerelease contains

- Carries forward the complete LogosForge Pro alpha feature set: the native
  Studio workspace, local managed Core, manuscript and planning tools, Decision
  Radar, Narrative Knowledge Graph, Semantic Continuity, Guided Workflows,
  transactional Timeline and Canvas editing, live invalidation, and the
  authenticated local MCP gateway.
- Keeps Continuity issue cards mounted during authoritative background refresh,
  so an exact Decision Radar deep link retains keyboard focus instead of being
  replaced by a transient loading surface.
- Makes the native packaged-app acceptance fixture revision-safe before editing
  manuscript prose, preserving real optimistic-concurrency and save-barrier
  behavior while removing a setup race exposed by Linux runners.
- Retains the v0.1.1 hardening for manuscript save-barrier diagnostics,
  Continuity focus retries, and observed transactional Timeline placement.

## Platforms

- Windows x64: NSIS installer and portable executable.
- Linux x64: AppImage.
- macOS Intel x64: DMG for macOS 12 Monterey or newer.

Apple Silicon and universal macOS packages are not included. Windows SmartScreen
and macOS Gatekeeper may warn because these builds are not yet code-signed or
notarized. On macOS, right-click the app and choose **Open**, or clear quarantine
with `xattr -cr "/Applications/LogosForge Pro.app"`.

## Suggested manual acceptance

1. Install or launch the native package and create or reopen a project.
2. Edit manuscript prose, switch between Focus and Cockpit, restart the app,
   and confirm the saved text and workspace layout return.
3. Open Decision Radar evidence in Knowledge Graph and Semantic Continuity;
   confirm exact deep-link focus and complete a reviewed Continuity decision.
4. Add scenes to Timeline, create and repair relationships, restart, and verify
   the authoritative structure remains intact.
5. Configure LM Studio or another supported provider and exercise Billy,
   Controlled Apply, and the authenticated local MCP gateway.

## Known limitations

- LogosForge Pro remains a local-first, single-user alpha without cloud sync or
  real-time collaboration. Web distribution is not part of this release.
- Hosted AI features require a configured provider such as a local LM Studio
  endpoint. Deterministic writing, planning, analysis, and export features stay
  available offline.
- Voice-model files are not bundled and must be supplied separately.
- Native packages are unsigned. Code signing, notarization, and Apple Silicon
  packaging remain future release work.
- MCP mutations require explicit server opt-in and retain proposal, review,
  revision, apply, and durable-receipt protections.
