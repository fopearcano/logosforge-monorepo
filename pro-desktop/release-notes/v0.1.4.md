# LogosForge Pro 0.1.4 — Alpha

> [!WARNING]
> This is alpha software. Keep independent backups of important work and export
> a `.lfbundle` regularly. The desktop packages are currently unsigned.

## What is new

- Turns every detached Pro panel into an independent, modeless native desktop
  window. A panel can now leave the main Studio frame and live on a second
  monitor while remaining part of the same project and React workspace.
- Uses the operating system's title bar, borders, focus, move, resize, minimize,
  and restore behavior. The panel bar retains L · C · R · B redocking,
  the FLOATS tray, and ordinary-panel close controls.
- Preserves the single-instance panel contract. Direct shortcuts focus or
  restore an existing native panel window instead of creating a duplicate, and
  Manuscript plus AI Companions remain non-closable permanent surfaces.
- Persists native outer-window bounds in display-independent screen coordinates
  for each project, including valid negative coordinates for monitors above or
  to the left of the primary display. When a display is disconnected or its
  work area changes, Studio recovers stranded windows into a visible work area.
- Keeps panel content mounted while it moves between the main document and its
  native window, so editor state, AI sessions, modal dialogs, runtime notices,
  and project-aware save barriers continue to operate from detached panels.
- Restricts native panel creation to the fixed Studio panel allowlist and an
  exact internal blank-window request. Detached windows inherit the hardened
  preload boundary, cannot navigate or create more windows, and carry no Node
  integration.
- Retains the browser fallback: Pro Web and the shared preview still provide
  contained workspace floats with the same docking controls when a native
  window host is unavailable.
- Carries forward the complete 0.1.3 feature set, including Skins, all-panel
  shortcuts, transactional Timeline and Canvas editing, Decision Radar,
  Narrative Knowledge Graph, Semantic Continuity, Guided Workflows, Controlled
  Apply, and the authenticated local MCP gateway.

## Platforms

- Windows x64: NSIS installer and portable executable.
- Linux x64: AppImage.
- macOS Intel x64: DMG for macOS 12 Monterey or newer.

Apple Silicon and universal macOS packages are not included. Windows SmartScreen
and macOS Gatekeeper may warn because these builds are not yet code-signed or
notarized. On macOS, right-click the app and choose **Open**, or clear quarantine
with `xattr -cr "/Applications/LogosForge Pro.app"`.

## Suggested manual acceptance

1. Detach Manuscript, AI Companions, and at least two ordinary panels. Confirm
   each becomes a separate operating-system window and remains usable when moved
   completely outside the main Studio window.
2. On a multi-monitor computer, move windows to different displays, including a
   display positioned above or to the left of the primary monitor. Restart Pro
   and confirm each project's arrangement returns.
3. Disconnect a display that contains a detached panel, relaunch Pro, and
   confirm the panel is recovered to a reachable work area without losing its
   saved placement kind.
4. Minimize a native panel, restore it from the FLOATS tray and its direct
   shortcut, then use L · C · R · B to redock it. Confirm no duplicate panel
   appears.
5. Edit Manuscript, Notes, PSYKE, Comments, and AI content from detached windows;
   switch projects and close the application, confirming pending work completes
   through the normal save barrier.
6. Enter and leave Focus mode and confirm native panels hide and return with
   their prior placement. Exercise dialogs and keyboard shortcuts from both the
   main window and a detached panel.

## Known limitations

- LogosForge Pro remains a local-first, single-user alpha without cloud sync or
  real-time collaboration. Web distribution is not part of this release.
- Browser hosts cannot create operating-system panel windows; they keep floats
  inside the browser workspace.
- Hosted AI features require a configured provider such as a local LM Studio
  endpoint. Deterministic writing, planning, analysis, and export features stay
  available offline.
- Voice-model files are not bundled and must be supplied separately.
- Native packages are unsigned. Code signing, notarization, and Apple Silicon
  packaging remain future release work.
- MCP mutations require explicit server opt-in and retain proposal, review,
  revision, apply, and durable-receipt protections.
