# LogosForge Pro 0.1.7 — Alpha

> [!WARNING]
> This is alpha software. Keep independent backups of important work and export
> a `.lfbundle` regularly. The desktop packages are currently unsigned.

## What is new

- Adds provider-neutral Cloud Folder Sync for complete Pro projects.
- Works with a normal local or offline-mirrored folder managed by Google Drive,
  Dropbox, OneDrive, iCloud Drive, or Syncthing. LogosForge itself needs no
  provider login, OAuth token, or cloud account.
- Publishes changed projects automatically every 10 minutes, with **Sync Now**
  available for immediate publishing.
- Discovers projects created on another device and imports complete snapshots.
- Handles divergent copies explicitly with **Keep Both**, **Use Cloud**, and
  **Replace Cloud** recovery choices instead of silently overwriting work.
- Exposes recovered provider branches in the Cloud Sync panel.
- Adds Cloud Sync to the detachable Pro workspace and native Window menu, with
  the `Cmd/Ctrl+Alt+Shift+1` shortcut.

## Safety and recovery

- Every snapshot first enters a durable local outbox before provider delivery.
- Complete project snapshots are immutable and committed without overwriting
  existing history.
- Durable action and restore receipts make interrupted operations retry-safe.
- Automatic pull occurs only when the local project is unchanged and the cloud
  history has one safe descendant.
- Conflicting histories remain separate and recoverable.
- Device-local paths, UI state, runtime queues, and command receipts are not
  synchronized.
- Snapshot files are plain JSON unless the selected provider or disk supplies
  encryption.

## Platforms

- Windows x64: NSIS installer and portable executable.
- Linux x64: AppImage built against the Ubuntu 22.04 baseline.
- macOS Intel x64: DMG for macOS 12 Monterey or newer.

Apple Silicon and universal macOS packages are not included. Windows SmartScreen
and macOS Gatekeeper may warn because these builds are not yet code-signed or
notarized. On macOS, right-click the app and choose **Open**, or clear quarantine
with `xattr -cr "/Applications/LogosForge Pro.app"`.

## Suggested manual acceptance

1. Select a provider-managed folder, enable automatic sync, and use **Sync Now**
   on a project with manuscript, Bible, structure, Progressions, and comments.
2. Open the same provider folder on a second device, discover the project, and
   import it.
3. Edit both copies independently and confirm Pro presents explicit conflict
   recovery choices while preserving both histories.
4. Interrupt a publish or restore, restart Pro, and confirm the queued action can
   safely resume without duplicate or overwritten snapshots.
5. Detach Cloud Sync to a second monitor, use its keyboard shortcut, and confirm
   the panel and native Window menu remain synchronized.

## Known limitations

- Cloud Folder Sync requires a normal local or offline-mirrored folder on a
  filesystem that supports atomic, no-clobber commits. Standard NTFS, APFS, and
  ext4 folders normally satisfy this requirement. Streaming-only, placeholder,
  or some FUSE-mounted folders may reject the commit; Pro keeps the snapshot
  queued locally until the folder is available offline or another folder is
  selected.
- Each changed publish creates a complete immutable recovery version. Pro does
  not silently prune history, so provider storage usage grows until older
  versions are deliberately removed.
- LogosForge Pro remains a local-first, single-user alpha; this release does not
  add real-time multi-user collaboration or web distribution.
- Hosted AI features require a configured provider such as a local LM Studio
  endpoint. Deterministic writing, planning, analysis, sync, and export features
  stay available offline.
- Voice-model files are not bundled. Native packages are unsigned, and Apple
  Silicon packaging remains future work.
