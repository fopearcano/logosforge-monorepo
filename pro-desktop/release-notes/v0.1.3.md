# LogosForge Pro 0.1.3 — Alpha

> [!WARNING]
> This is alpha software. Keep independent backups of important work and export
> a `.lfbundle` regularly. The desktop packages are currently unsigned.

## What is new

- Adds **Skins** to the Pro workspace. Choose the original Forge atmosphere,
  the neutral Paper workspace, or the warmer Lamplit environment from the
  navigator, the View menu, or the command palette. The choice is remembered
  on the current device and does not alter project content or layout.
- Makes all 37 Pro panels—including Manuscript and AI Companions—first-class
  movable surfaces. Every panel can live in any dock or detach into a modeless
  floating window that can be moved, resized, minimized, restored, raised, and
  redocked.
- Persists each project's complete workspace arrangement: dock order and active
  tabs, floating bounds and stacking, minimized panels, and collapsed docks.
  Manuscript and AI Companions remain non-closable so the permanent writing and
  assistant surfaces are always recoverable.
- Gives every panel a unique direct open/focus shortcut, mirrored in the native
  **Go** menu and the in-app Help guide. A shortcut opens a closed panel,
  activates a docked panel, or restores and raises its existing float without
  duplicating or remounting it.
- Keeps Focus mode non-destructive: Manuscript is temporarily projected into
  the full center workspace, and leaving Focus restores the exact Cockpit
  arrangement and keyboard focus.
- Improves responsive workspace chrome and accessible keyboard operation for
  smaller displays, floating title bars, resizers, dock controls, and dialogs.
- Carries forward the complete 0.1.2 Pro feature set, including transactional
  Timeline and Canvas editing, Decision Radar, Narrative Knowledge Graph,
  Semantic Continuity, Guided Workflows, Controlled Apply, and the authenticated
  local MCP gateway.

## Platforms

- Windows x64: NSIS installer and portable executable.
- Linux x64: AppImage.
- macOS Intel x64: DMG for macOS 12 Monterey or newer.

Apple Silicon and universal macOS packages are not included. Windows SmartScreen
and macOS Gatekeeper may warn because these builds are not yet code-signed or
notarized. On macOS, right-click the app and choose **Open**, or clear quarantine
with `xattr -cr "/Applications/LogosForge Pro.app"`.

## Suggested manual acceptance

1. Choose each Skin, restart the app, and confirm the selected atmosphere is
   restored without changing the project or workspace layout.
2. Float Manuscript, AI Companions, and several ordinary panels; move and resize
   them, minimize one to the FLOATS tray, redock another, restart, and confirm
   the exact arrangement returns.
3. Exercise the shortcuts listed in Help → Open or focus a panel, including a
   closed panel, a docked panel, and a minimized floating panel.
4. Enter and leave Focus mode and confirm the pre-Focus Cockpit arrangement,
   active panel, manuscript draft, and keyboard focus are preserved.
5. Configure LM Studio or another supported provider and exercise Billy,
   Controlled Apply, and the authenticated local MCP gateway.

## Known limitations

- LogosForge Pro remains a local-first, single-user alpha without cloud sync or
  real-time collaboration. Web distribution is not part of this release.
- Hosted AI features require a configured provider such as a local LM Studio
  endpoint. Deterministic writing, planning, analysis, and export features stay
  available offline.
- Voice-model files are not bundled and must be supplied separately.
- Native packages are unsigned. Code signing, notarization, and Apple Silicon
  packaging remain future release work.
- MCP mutations require explicit server opt-in and retain proposal, review,
  revision, apply, and durable-receipt protections.
