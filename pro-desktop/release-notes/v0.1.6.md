# LogosForge Pro 0.1.6 — Alpha

> [!WARNING]
> This is alpha software. Keep independent backups of important work and export
> a `.lfbundle` regularly. The desktop packages are currently unsigned.

## What is fixed

- Fixes the red `ResizeObserver loop completed with undelivered notifications`
  banner that could appear when Pro opened with detached native panels.
- Rebinds Quantum Outliner layout observers to the window that actually hosts
  the panel, including restored AI Companions windows on a second monitor.
- Coalesces native-panel measurements into the owning window's animation frame,
  avoids redundant layout updates, and cancels pending work when panels move or
  close.
- Keeps genuine application failures visible while recognizing only Chromium's
  two exact non-fatal ResizeObserver delivery notifications.
- Adds packaged-app regression coverage for restarting Pro with AI Companions
  detached, Billy selected, and Quantum mounted in the background.
- Retains the Progressions, Knowledge Graph, Decision Radar, transactional
  Timeline and Canvas, MCP orchestration, Skins, and multi-monitor workspace
  features introduced through 0.1.5.

## Platforms

- Windows x64: NSIS installer and portable executable.
- Linux x64: AppImage.
- macOS Intel x64: DMG for macOS 12 Monterey or newer.

Apple Silicon and universal macOS packages are not included. Windows SmartScreen
and macOS Gatekeeper may warn because these builds are not yet code-signed or
notarized. On macOS, right-click the app and choose **Open**, or clear quarantine
with `xattr -cr "/Applications/LogosForge Pro.app"`.

## Suggested manual acceptance

1. Detach AI Companions with Billy selected, quit Pro normally, reopen it, and
   confirm the native window returns without a red UI error banner.
2. Move Manuscript and AI Companions between the main display and a second
   monitor, then dock and detach them again while checking that their layouts
   remain responsive.
3. Confirm Progressions, Timeline, Canvas, Knowledge Graph, and Decision Radar
   data still survive a normal restart.
4. Connect an MCP client and confirm project discovery, context reads, proposals,
   review, and guarded apply operations remain available.

## Known limitations

- LogosForge Pro remains a local-first, single-user alpha without cloud sync or
  real-time collaboration. Web distribution is not part of this release.
- Hosted AI features require a configured provider such as a local LM Studio
  endpoint. Deterministic writing, planning, analysis, and export features stay
  available offline.
- Voice-model files are not bundled and must be supplied separately.
- Native packages are unsigned. Code signing, notarization, and Apple Silicon
  packaging remain future release work.
- MCP mutations require explicit server opt-in and retain proposal, review,
  revision, apply, and durable-receipt protections.
